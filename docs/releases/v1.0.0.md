# AI Terminals v1.0.0

Prima release stabile per Windows x64.

Due applicazioni autonome, con motore ConPTY e renderer xterm.js condivisi:

- **Claude Terminal**: grafica terracotta, conversazioni Claude Code, progetti e sessioni simultanee.
- **Codex Terminal**: grafica grafite/teal, Codex CLI, storico con titoli e sessioni parallele.
- Passaggio tra conversazioni senza riavviare i processi, ricerca, ripresa sessioni e statistiche token locali.
- Nuova riga: Shift+Invio in Claude; Shift+Invio/Ctrl+Invio/Ctrl+J in Codex, secondo la CLI installata.
- Icone distinte, due pacchetti portabili Windows self-contained.

## Pacchetti

- ClaudeTerminal-win-x64.zip
- CodexTerminal-win-x64.zip
- SHA256SUMS.txt: SHA-256 di entrambi gli archivi.

**Estrarre l'intero ZIP**, non solo l'EXE, mantenendo le sottocartelle insieme al programma.

Per chi usa la copia locale del repository, il comando PowerShell
`& '.\scripts\Install-AITerminals.ps1' -App Both`
aggiorna le cartelle già esistenti, senza alias e senza download ZIP manuali.

## Requisiti e privacy

Windows x64, WebView2 Runtime, PowerShell 7 (pwsh) e le rispettive CLI Claude/Codex disponibili sul PC.
Nessun .NET SDK o Node.js richiesto sul PC destinatario. I transcript e le credenziali rimangono locali.
Le statistiche token non indicano la quota residua o i costi effettivamente addebitati.

L'icona Codex è una grafica personalizzata, non il logo ufficiale OpenAI.
