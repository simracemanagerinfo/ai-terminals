# AI Terminals v1.0.1

Aggiornamento correttivo della release v1.0.0 per Windows x64.

## Correzione Claude Terminal

- Nello storico mostra i titoli persistenti delle conversazioni anziché sempre la prima domanda.
- Priorità: rinomina `/rename`, titolo automatico Claude Code, riepilogo, prima domanda come fallback.
- Riconosce i titoli comparsi più avanti nel transcript (anche in sessioni lunghe).
- Cache per non rileggere ogni 15 secondi le conversazioni invariate.
- Compatibilità con `CLAUDE_CONFIG_DIR` e ignoranza dei record JSONL incompleti.
- Nessuna modifica ai transcript o alle credenziali.

## Codex Terminal

Nessuna variazione funzionale rispetto a v1.0.0.

## Pacchetti

- `ClaudeTerminal-win-x64.zip`
- `CodexTerminal-win-x64.zip`
- `SHA256SUMS.txt`

Per aggiornare solo Claude dall'installazione locale del repository:

```powershell
& '.\scripts\Install-AITerminals.ps1' -App Claude
```

Estrarre l'intero archivio ZIP se si usa il download manuale. Servono Windows x64, PowerShell 7, WebView2 Runtime e la CLI dell'agente installata.
