# AI Terminals v1.1.0

**Two independent Windows applications** for working with Claude Code and Codex CLI. Open projects, run several conversations at once, resume local history and check token usage — all in a dedicated terminal window.

### What's new
- **Organize chats:** create virtual folders, drag conversations between them, or right-click a folder → **New conversation here**.
- **Bin / Secchio:** hide unwanted chats and restore them later. **No conversation files are deleted.**
- **Completion alerts:** highlight finished chats and show a small clickable popup when the terminal is in the background.
- **English & Italian:** choose the UI language at any time.
- **Fixes:** improved Claude session startup on Windows and more reliable release installation.

### Install / update
**Requirements:** Windows x64, PowerShell 7, WebView2 Runtime, and the Claude Code and/or Codex CLI installed and available in PATH.

Close both terminal apps. Run the following in **PowerShell 7**, from any directory:

```powershell
$installer = Join-Path $env:TEMP 'Install-AITerminals.ps1'
Invoke-WebRequest -Uri 'https://raw.githubusercontent.com/simracemanagerinfo/ai-terminals/main/scripts/Install-AITerminals.ps1' -OutFile $installer
& $installer -App Both
```

The installer updates the existing applications and verifies the downloaded archives. **No GitHub login is required for stable releases.** To update only one, use `-App Claude` or `-App Codex`.

[Full guide](https://github.com/simracemanagerinfo/ai-terminals#readme) · [Guida in italiano](https://github.com/simracemanagerinfo/ai-terminals/blob/main/docs/README.it.md)

*Note: folders and the Bin are visual only. New Codex chats are placed in the chosen folder once Codex reports their actual session ID, usually after the first response.*
