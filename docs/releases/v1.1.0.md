# AI Terminals v1.1.0 — Windows x64

This release adds **completion notifications, reversible conversation organization, and English/Italian localization** to both independent terminals.

## Highlights

- **Claude Terminal and Codex Terminal** remain separate Windows executables sharing one WPF/ConPTY/xterm.js implementation. Installation updates their existing locations without introducing aliases.
- **Response complete**: the selected conversation is marked as unread after a real CLI completion event (Claude `Stop` hook; Codex `agent-turn-complete`). A compact, non-activating WPF popup appears when the app is in the background and clicking it returns to the specific chat.
- **Virtual folders per project and agent**: create, rename and remove categories; right-click a stored conversation to move it between folders.
- **Bin / Secchio** always appears last and is initially collapsed. It performs logical deletion only; Restore returns the conversation to its previous folder. No Claude/Codex transcript or index is deleted or moved.
- **Drag and drop**: move historical conversations by dragging them onto folder headers (including the Bin). Active sessions are not draggable.
- **New conversation here** in folder right-click menu. Claude's conversation is assigned to the folder when created; Codex assigns it once its first completion event exposes the actual stable thread ID. The apps never invent Codex conversation IDs.
- **English / Italiano**: language chooser, OS language detection, central translation catalogue, localized main window, token usage, notifications and launcher diagnostics.
- **Claude startup fix**: passes notification hook settings via a temporary valid JSON file, rather than inline JSON that `claude.cmd` can corrupt on Windows.
- **Public installer**: stable GitHub Releases can be installed without authenticating to GitHub. Actions preview builds continue to require authorized artifact access. SHA-256 checksums are always validated for stable releases.
- **Claude conversation titles** improved in v1.0.1 remain supported.

## Requirements

Windows x64, PowerShell 7, WebView2 Runtime and the relevant CLI (`claude` / `codex`) available in `PATH`. Each portable app contains its own .NET 10 runtime. No administrator rights are required by the portable installation.

## Install or update (PowerShell 7, any current directory)

Close the app windows first, then execute:

```powershell
$ErrorActionPreference = 'Stop'
$installer = Join-Path $env:TEMP 'Install-AITerminals.ps1'
Invoke-WebRequest -Uri 'https://raw.githubusercontent.com/simracemanagerinfo/ai-terminals/main/scripts/Install-AITerminals.ps1' -OutFile $installer
& $installer -App Both
```

To update just one app, use `-App Claude` or `-App Codex`.

## Safety and limitations

Folder changes and the Bin are *visual metadata only*, scoped by project and application. They never remove or move CLI transcripts. A Codex new chat created from a folder is automatically filed after the first successfully reported reply; if Codex never produces a completion event, it may remain in Unorganized. Drag/drop is restricted to historical chats. The WPF popup is not a Windows Action Center notification and may be covered by exclusive fullscreen apps.

Hooks are configured per launched CLI instance; they do not edit global configuration but can supersede a user-customized notifier for that process.

Automated Windows CI covers PowerShell launch/resume/hooks, history parsing, folder persistence, completion marker correlation and x64 packaging. Actual GUI popup, dragging and agent runtime behavior were evaluated separately as preview features; final new-context-menu behavior should be verified on a real Windows desktop.
