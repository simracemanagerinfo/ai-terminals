# AI Terminals v1.1.1

**Claude Terminal and Codex Terminal** are two independent Windows apps for opening projects, managing parallel AI conversations and viewing local session history.

### New: one-click Windows installer

**Download `AI-Terminals-Setup.exe` and open it.** Choose Claude Terminal, Codex Terminal, or both. The installer works offline, requires **no administrator rights**, creates Start menu entries, and keeps your existing conversations, virtual folders and settings. You can optionally create desktop shortcuts.

No PowerShell script, GitHub login or manual ZIP extraction is required for installation.

### Included features

- Project-based conversation folders, drag & drop and **New conversation here**. **Running chats remain in their folder** (with an active status indicator) and keep that organization when closed. Right-click or drag an active chat to change its folder; chats from other projects stay accessible in a separate active section.
- **Bin / Secchio** hides chats without deleting their files; restore any time.
- Clickable response-completion notifications and unread conversation indicators.
- English / Italian interface, local token statistics and persistent session history.

**Requirements:** Windows x64, PowerShell 7, Microsoft WebView2 Runtime, and the Claude Code and/or Codex CLI installed separately and available in `PATH`. The setup EXE does not install or configure those third-party command-line agents.

**Other downloads:** `ClaudeTerminal-win-x64.zip` and `CodexTerminal-win-x64.zip` remain available for portable/manual installations. `SHA256SUMS.txt` provides checksums for all three downloads.

**Windows security:** The installer is not yet digitally signed. Windows SmartScreen may warn about an unfamiliar executable, and company security policies may block it. We do not recommend disabling Windows security protections.
