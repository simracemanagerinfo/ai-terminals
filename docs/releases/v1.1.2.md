# AI Terminals v1.1.2

**Maintenance release for Claude Terminal and Codex Terminal on Windows.** The two applications remain independent, with a shared ConPTY/xterm.js terminal implementation.

### Fixed

- **PowerShell updates from public GitHub Releases:** read `SHA256SUMS.txt` reliably when GitHub serves the downloaded file as binary data. Keep strict SHA-256 validation for both downloadable ZIPs, and validate the checksum before downloading large archives.
- **Folder startup:** virtual project folders and **Unorganized** now start collapsed instead of all expanded. The Bin remains collapsed; opening or selecting a running chat automatically expands its own folder.
- Existing virtual folders, conversation placements, history, language selection and process settings are preserved across updates.

### Install / update

**Download [AI-Terminals-Setup.exe](https://github.com/simracemanagerinfo/ai-terminals/releases/tag/v1.1.2) and double-click**, or update the two existing apps with the [PowerShell installer](https://github.com/simracemanagerinfo/ai-terminals/blob/main/scripts/Install-AITerminals.ps1) from this repository.

The setup supports either app or both, requires no administrator permissions and keeps the existing per-user application folders. Portable ZIP downloads and `SHA256SUMS.txt` are also included.

**Requirements:** Windows x64, PowerShell 7, Microsoft WebView2 Runtime, and the corresponding Claude Code and/or Codex CLI installed separately in PATH. The installer is not yet code-signed, so Windows SmartScreen or organizational security policies may warn or block it. Do not disable Windows security features.

**Folder actions:** right-click a folder heading → **New conversation here** (Italian: **Nuova conversazione qui**). It is a context-menu action, not a permanent button. Active chats retain their folder after closing.
